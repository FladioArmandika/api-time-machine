# data/

Everything in this folder is generated by `pipeline/` (`npm run build`). The site reads only this folder.

| File | What it holds |
|---|---|
| `leaderboard.json` | APIs ranked by stability score, with trailing-12-month counts |
| `headlines.json` | The findings as sentences, most striking first |
| `apis/<id>.json` | One API: monthly snapshots, every interval's breaking changes, per-year totals, score |
| `meta.json` | When it ran, the oasdiff version and the score parameters |
| `cache/<id>/specs.json` | Per spec blob: OpenAPI version, operation count, or why it couldn't be read |
| `cache/<id>/diffs/<base>-<rev>.json` | oasdiff results for one pair of spec blobs. A pair never changes, so it's never diffed twice |

## How the history is sampled

For every month since the spec file first appeared, the pipeline takes the tip of the default branch at the end of that month (first-parent). That's the spec as it actually stood on `main`. Months where the file didn't change are skipped. The current month counts as a partial snapshot and gets replaced on every run.

Consecutive snapshots are compared with `oasdiff changelog`. A snapshot that is missing or isn't OpenAPI 3 (OpenAI's 2025–26 hole, Swagger 2.0) splits the timeline into a **gap**. Diffs that span a gap aren't counted.

Vendor specs are often slightly invalid: a `$ref` to a deleted schema, a ref into an unpublished file, or a ref that points inside another component. oasdiff refuses to load those. When that happens, the pair is diffed again on repaired copies: broken refs become empty schemas, deep refs are inlined, and dead discriminator mappings are dropped (`pipeline/src/sanitize.ts`). The interval records `repairedRefs`, and changes inside the broken parts are invisible. Most of PagerDuty's and Cloudflare's history needs this.

Each diff gets 6 minutes and 10 GB (`OASDIFF_MAX_GB`). If the current month runs out of either, it is retried on the next run. One Stripe pair from spring 2019 makes oasdiff use more than 14 GB, so it's recorded as an error interval and left out of the counts.

## What counts as a breaking change

oasdiff's own rules decide, with one adjustment, in [`pipeline/config/severity-levels.txt`](../pipeline/config/severity-levels.txt):

- **Hard break** (oasdiff `ERR`): a removed endpoint or property, a type change, a request field that became required, a response field that became nullable, and so on.
- **Soft break** (oasdiff `WARN`, plus additive response changes we downgrade from `ERR`): a new enum value, a new `anyOf`/`oneOf` branch or a relaxed constraint in a response. Strict generated clients can choke on these. Most vendors document them as safe.

oasdiff reports a schema change once for every endpoint and nesting path that uses it. Stripe adding one enum value can produce 7,000 findings. API Weather groups them by rule and by the change's text with schema paths shortened, so that becomes **one change** affecting N endpoints. Counts on the site are these grouped changes. The raw counts are kept too.

## Stability score

```
penalty(m) = (hard_m + 0.25 · soft_m) / (operations_m / 100)
B          = Σ over the last 12 months of 0.5^(months_ago / 6) · penalty(m)
score      = round(100 · exp(−B / K))
```

- The penalty is measured per 100 operations, so a big API isn't punished for being big.
- Recent months count more, with a half-life of 6 months.
- `K` was calibrated once, on the first backfill, and is now frozen so scores stay comparable over time (see `pipeline/src/score.ts`).
- Labels: ☀️ Clear 85+, 🌤 Fair 70–84, 🌧 Showers 50–69, ⛈ Storms under 50.

**Breaking months** is the plain number of the last 12 months with at least one hard break. The headlines use it because it needs no explanation.

## Caveats

- Stripe, GitHub and Plaid version their APIs. A break in the latest spec doesn't break clients pinned to an older version until they upgrade. The numbers here describe how often the *latest contract* changes.
- A published spec isn't the API itself. A vendor fixing an inaccurate spec shows up as a change even when the live API didn't move.
- Monthly sampling hides anything added and removed within the same month.
